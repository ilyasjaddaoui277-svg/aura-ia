REST API & Quickstart Integration

Connect any frontend or backend service to your AI prompt studio endpoint in minutes with clean JSON payloads.

1. Execute Prompt Endpoint

Send a structured prompt payload with your preferred tone and model tier. Switch between cURL, JavaScript, and Python examples below.

POST https://api.example.com/v1/prompts/execute 
curl -X POST https://api.example.com/v1/prompts/execute \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "aura-pro-reasoning",
    "tone": "executive",
    "language": "en",
    "prompt": "Generate a B2B SaaS launch checklist."
  }'
const response = await fetch("https://api.example.com/v1/prompts/execute", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    model: "aura-pro-reasoning",
    tone: "executive",
    language: "en",
    prompt: "Generate a B2B SaaS launch checklist."
  })
});
const data = await response.json();
console.log(data.output);
import requests

res = requests.post(
    "https://api.example.com/v1/prompts/execute",
    headers={"Authorization": "Bearer YOUR_API_TOKEN"},
    json={
        "model": "aura-pro-reasoning",
        "tone": "executive",
        "language": "en",
        "prompt": "Generate a B2B SaaS launch checklist."
    },
    timeout=30,
)
print(res.json()["output"])

3. Rate Limits & HTTP Status Codes

        
    
          
  • 200 OK — Prompt executed successfully with token usage metadata.
    • 
          
  • 400 Bad Request — Prompt shorter than 15 characters or invalid JSON.
    • 
          
  • 401 Unauthorized — Missing or invalid Bearer API token.
    • 
          
  • 429 Too Many Requests — Plan rate limit exceeded; retry with exponential backoff.
